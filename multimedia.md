# Multimedia Syntax Guide

This wiki supports embedding various media types directly into your pages using special link syntax.

## 1. Images
Embed images stored in the image gallery.

- **Basic Embed:** `![[filename.png]]`
- **Embed with Caption:** `![[filename.png|Your Caption]]`

## 2. PDFs
Embed PDF documents stored in the PDF gallery.

- **Basic Embed:** `![[document.pdf]]`
- **Embed with Custom Height:** `![[document.pdf|800]]` (Height in pixels)

## 3. Audio
Embed audio files stored in the audio library.

- **Basic Embed:** `![[audio_clip.mp3]]`
- **Embed with Caption:** `![[audio_clip.mp3|A relaxing melody]]`

## 4. Videos
Embed video files stored in the video library or from YouTube.

### Local Videos
- **Basic Embed:** `![[video_clip.mp4]]`
- **Embed with Custom Width:** `![[video_clip.mp4|640]]` (Width in pixels)

### YouTube Videos
- **Basic Embed:** `![[https://www.youtube.com/watch?v=VIDEO_ID]]`
- **Embed with Caption:** `![[https://www.youtube.com/watch?v=VIDEO_ID|Description here]]`
